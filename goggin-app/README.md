# Goggin

A habit tracker with colorful dot grids, streaks and a calendar history.

## Files

| File | What it is |
|---|---|
| `goggin.html` | The working prototype (one file: HTML, CSS and JavaScript) |
| `PROGRESS.md` | Progress log: features, data model, to-do list and changelog |

## Running it

Open `goggin.html` in a browser. Data is saved on the device (localStorage key `goggin-v1`).
